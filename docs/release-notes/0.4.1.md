# ego 0.4.1

Prepared for release after `0.4.0`.

## Fixes

- Release the session writer lock before closing its file on Unix. Reopening a
  session in the same process no longer reports a lock that the process has
  already finished using.
- Repair the release checks: remove a duplicate dependency-audit option, make
  filesystem checks read UTF-8 consistently on Windows, and make sandbox test
  fixtures independent of host defaults and optional Linux capabilities.
  (regression case, regression case, regression case, regression case)
- Isolate concurrent doctor-test observations so checks do not interfere with
  one another in the ordinary test runner. This changes test fixtures, not the
  doctor command.
- Add startup regression coverage to keep the identity banner and logo out of
  quiet, piped, and plain output. This adds tests, not a new startup behavior.

- Correct the documentation to distinguish the published `0.4.0` tag from
  release-asset availability and remaining product validation.

## Breaking changes

None.
