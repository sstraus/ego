# ego 0.4.3

Prepared locally after the `0.4.2` preparation. This version is not tagged or
published. These notes cover changes merged since `9d14852ef`.

## Features

- Configure a user-owned provider protocol filter to transform outgoing HTTP
  generation bodies and incoming streamed bytes before provider decoding.
  Filters can return declared non-secret identity headers and retain write-once
  session variables across resume and continue. Invalid output or filter failure
  stops generation; ego does not fall back to unfiltered traffic. See the
  [protocol-filter guide](../integrations/protocol-filter.md).
- Grant an extra filesystem root from the owning human terminal for the session
  or save a permanent grant in the selected user profile. Exit and resume the
  same session to admit the new authority; grants do not change an active OS guard.
  Revoke a grant with `/config roots revoke EXACT_PATH`; revocation cancels the
  active turn and rebuilds the session with narrower authority.
- Send richer native terminal events to TUICommander for tools, child activity,
  turn outcomes, and actual permission or question presentations. Events carry
  native identities without private task text, tool arguments, results, or human
  answers. Ordinary terminals and JSON/JSONL output do not receive these frames.

- Let ACP v1 clients opt in to native child lifecycle metadata. Load and resume
  provide the current durable child roster without replaying historical starts.
  Durable children can outlive their parent turn; turn retraction clears only
  foreground children. See [ACP child activity](../integrations/acp-extensions.md#child-activity-negotiated-version-1).

- Resume the most recently updated readable session in the current workspace
  directly with `ego --continua`, without opening the session picker or creating
  a session.
- Open live-terminal selectors with bare `/mcp` and `/skills`, improve slash-menu
  contrast and MCP inventory alignment, and group startup MCP notices in the
  terminal while preserving detailed headless diagnostics.

## Fixes

- Keep submitted prompts and later input live when cursor-position replies are
  missing after initialization, including full prompt receipts that scroll beyond
  the screen. Preserve input through a provider retry and background completion
  wake.

- Exit ACP on SIGTERM and settle an active turn before shutdown.
- Include the advertised child activity capability in the pinned ACP compatibility
  snapshot; child updates still require explicit client opt-in.

- Negotiate the Kitty keyboard protocol on supported terminals so Ctrl+Enter
  remains distinct from Enter. Release keyboard modes before Ctrl+Z suspension
  and restore them when the editor resumes; unsupported terminals retain their
  existing input behavior.
- Recover abandoned workspace execution-probe fixtures during later capability
  measurements. Active probes and unmarked directories are not removed.

- Preserve terminal output after a matched setup marker so coalesced output does
  not cause a later setup wait to miss its marker.

## Breaking changes

- Public event schema advances from 18 to 19 with typed child lifecycle events.
  Consumers that reconstruct child rosters from durable history must also use
  the child lifecycle projection. ACP remains protocol version 1, and child
  activity metadata requires explicit client negotiation. (regression case, regression case)
