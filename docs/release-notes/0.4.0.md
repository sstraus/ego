# ego 0.4.0

Local release preparation. No tag, published binary, or Homebrew availability is
claimed. Changes below are from Git history after the `0.3.0` preparation commit
`bf155c469`, reviewed through `2f48474a` on master.

## Features

- Show the number of hidden terminal rows and the expansion shortcut below
  collapsed read, write, edit, and other non-exec tool results. Keep the existing
  exec tail and prompt preview. Successful edits use actual added/removed totals
  from the builtin receipt when available, including repeated edits.
- Add `/pin <text>`, `/pin` (or `/pin list`), and `/unpin <n>` for explicit
  session constraints. Pins persist through restart, compaction, and forks
  independently of model summaries. This is not automatic extraction of standing
  instructions from ordinary prose.
- Add observed context capacity and provider remaining-limit facts to
  `ego usage --json`. Missing observations stay absent; quota observations are
  not additive spend or inferred account balances.
- Add `--proxy http://HOST[:PORT]` and `--proxy-ca FILE` to `ego run`,
  interactive `ego`, and `ego resume`. They send provider HTTPS through one
  explicit HTTP CONNECT proxy for the invocation. Ambient proxy variables are
  ignored, there is no direct fallback, and `--offline` refuses a proxy. The
  implementation was recovered in `87607fedf` and reviewed and landed under
  regression case; the reference and completions were regenerated in regression case.
- Give foreground `exec` calls a default two-minute lifetime. `timeout_ms`
  accepts up to ten minutes, and the transcript row shows the effective limit.
  Background calls keep no default deadline.
- Show one activity row for each live durable background task in the attached
  interactive session, also while the parent is idle.
- Colour the command syntax in `exec` transcript receipts.

## Fixes

- Continue generations when prices or actual costs are unknown, with a durable
  cost-anomaly notice once per session/model. A monetary cap covers known
  spend only: unpriced work has no finite monetary bound, and unknown actual
  cost adds no invented estimate to spend. OpenRouter admission uses prompt
  rates for missing standard cache rates without inventing missing base prices.

- Enforce monetary caps against recorded response spend. Worst-case monetary
  reservations and estimated fallback charges are removed. A new request is
  refused only after recorded spend exceeds the cap; requests already admitted,
  including concurrent parent/child requests, can settle in full.
- Keep headless resume free of implicit interactive retry defaults.
- Exclude manifest-only sessions from the session catalogue and identify missing
  ACP sessions with their backing-store location.
- Execute advertised ACP skill commands through the shared skill-command path,
  including plain instruction skills without command templates.
- Append semantic host-context changes instead of repeated full inventories and
  avoid repeated admission of the same skill instructions.
- Omit empty process-stream labels from expanded tool output while retaining
  stream provenance.
- Update dependencies for RUSTSEC-2026-0381, -0382, -0383, and -0385, and replace
  the yanked `clipboard-win` version.
- Explain the explicit read-write root grant and exit/resume needed for writes
  outside the workspace, including linked worktrees. Worktree discovery does not
  grant authority automatically.
- Do not cache failed filesystem-capability probes as successful observations of
  no capabilities. Complete deferred ACP configuration offers with an error
  when confinement measurement fails; prompt admission still fails closed.
  (regression case, regression case)
- Correct the documentation for retry/fallback availability, the default 24-hour
  interactive/ACP recovery horizon, ACP forks, and hook inspection. These are
  documentation corrections, not runtime changes. This correction also appears
  in the updated `0.3.0` release notes.
- Label uncommitted conformance recordings as local evidence paths rather than
  repository links. No new conformance result is claimed.
- Persist a successful in-session model switch to the session.
- Restore implicit retry authority when a session resumes on a terminal seat.

- Keep the latest user request verbatim in compaction checkpoints, and render
  fork constraints once in the composed history. (regression case, regression case)
- Keep unknown slash-prefixed text as a modal answer.
- Keep prompt admission after a late terminal cursor reply, and keep the
  current activity when a modal closes. (regression case, regression case)
- Skip sessions whose log existence probe fails in the session catalogue.

- On macOS, admit the Apple launcher runtime in the sandbox profile and ask for
  permission on Seatbelt selector denials.
- Quote outside-read-root hints so they can be pasted, and offer an exact read
  grant when the sandbox denies an explicit shell script read. (regression case,
  regression case)
- Name backend revision changes in the consent prompt.
- Redact encoded Basic credentials, and keep ordinary prose that mentions the
  Basic or Bearer schemes.
- Make content search refuse special files and bound single-file reads.

- Do not give `pnpm` an unsafe optional lock directory, and give a racing
  background promotion and foreground completion one owner. (regression case,
  regression case)

## Breaking changes

- Public-event schema v18 replaces v16 and adds the durable `CostAnomaly`
  projection with an optional, closed pricing-source `cause`. Event consumers
  must accept the new schema version and event. Raw price-source errors are
  not published. (regression case, regression case)
- The usage-report schema v4 replaces v3. It adds optional session context
  capacity and provider-limit observations, plus current-credential provider
  limits at report level. Closed-schema consumers must update; existing token
  and monetary accounting meanings are unchanged.
- Collapsed transcript text now includes hidden-row hints.

## Verification limits

This preparation does not establish final product conformance, real MCP OAuth
login/restart acceptance, hosted cross-platform builds, or Windows confinement
support. Pins preserve explicit constraint text, not a guarantee of model
obedience. Unknown spend is not zero and is not covered by a strict monetary
ceiling when no usable quote exists. This document does not claim release-asset
or Homebrew publication.
