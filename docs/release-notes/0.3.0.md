# ego 0.3.0

Local release preparation. No tag, published binary, or Homebrew availability is
claimed. Changes below are from Git history after the `0.2.0` version commit
`31525cea4`.

## Features

- Log in to an HTTP MCP server with `/mcp login NAME`. Successful login reconnects
  its tools in the current session; Escape cancels the login.
- Show a separate cyan activity row for each running child agent.
- Prepare five stable executable asset names, target-triple archives, individual
  SHA256 files, and a generated Homebrew formula for authorized publication.
  The source installer replaces the executable atomically without stopping
  existing sessions.

## Fixes

- Wake an idle interactive session when background execution settles, including
  cancelled work, so the model can receive the retained result.
- Advertise flat object schemas for `notebook_edit`, `plan`, and `skill`, so
  providers that reject root union schemas can accept the catalogue.
- Accept empty, unused sibling fields in flat `skill` requests without changing
  the selected operation.
- Read skill resources relative to the captured skill root, not the current
  working directory.
- Keep sanitized upstream error details and validation identifiers in diagnostics
  while removing credentials. (regression case, regression case)
- Preserve a configured Anthropic gateway's base-path prefix.
- Accept public OAuth dynamic-registration replies that omit the authentication
  method when they contain no client secret.
- Let confined processes signal their own descendants without granting authority
  over unrelated processes.
- Recognize Python script read denials in the sandbox grant flow.
- Clear settled interrupt and consumed queue indicators from the status row.

- Use plain next-step wording for refusals and login notices. Keep background
  completion notices separate from model text.

## Breaking changes

- No intentionally breaking public command or configuration change was identified
  in the reviewed history. The tool-schema fixes above change advertised request
  shapes; callers should use the catalogue supplied by their running session.
  (regression case, regression case)

## Verification limits

Real MCP OAuth login/restart acceptance, final product conformance, and hosted
cross-platform release builds remain separate gates. The release workflow has not
published these assets. Preparation does not establish vendor availability,
Homebrew tap readiness, or Windows confinement support.
