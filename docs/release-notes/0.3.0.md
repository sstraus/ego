# ego 0.3.0

This archived page is superseded. The [changelog](../changelog.md), section
`0.3.0`, is the authoritative record of the changes in this version.

Version 0.3.0 contains two breaking changes: the public event schema advanced
from 15 to 16, and the tool schemas of `notebook_edit`, `plan` and `skill`
became flat objects. Version 0.3.0 has no Git tag.
