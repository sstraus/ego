# ego 0.4.2

Prepared locally after the `0.4.1` preparation. This version is not tagged or
published. These notes cover changes merged since `61c3dc223`.

## Features

- Run independent subagent work in parallel. An idle interactive parent wakes
  when a background subagent settles and collects its result at a generation
  boundary. (regression case, regression case)
- Start the requested work when setting an interactive goal. Extend an active
  goal's automatic-turn allowance with `/goal extend N` or the metadata-only
  `--goal-operation extend=N` on resume or continue. Extension itself does not
  start work. (regression case, regression case)
- Run a local shell command from the idle interactive prompt with `!COMMAND`.
  Its output becomes context for the next turn; deny rules and process
  confinement still apply. Use `!!` for a literal leading exclamation mark.

- Open anchored history results and follow bounded continuation pages back to
  original session evidence. Tool evidence remains opt-in.
- Show inline diffs for successful unique edits, resolve relative Markdown links
  against the run workspace, and use useful output rows for compact process
  previews while retaining the complete expansion. (regression case, regression case)
- Guide user-default and profile configuration through terminal setup, with
  review and confirmation before an atomic save. Update the command reference
  and completions.


## Fixes

- Keep the Codex request prefix stable by appending hook-context changes after
  history. Earlier observations remain historical evidence, and expired context
  is identified explicitly. This removes a source of prompt-cache invalidation;
  it does not guarantee a provider cache hit.
- Keep Expand responsive while a turn finishes output, and leave the last
  terminal row free below the prompt. (regression case, regression case)
- Label a stopped goal continuation as paused, and strike only the recovered
  cause in a provider-error receipt. (regression case, regression case)
- Preserve both the canonical executable target and its invoked name, and fix
  the ACP write-scoped workspace probe. (regression case, regression case)

## Breaking changes

- The project license changes to Apache-2.0.
- Interactive setup no longer accepts a prompt argument; use
  `ego setup --profile NAME --directory PATH` and the terminal configuration
  guide.
