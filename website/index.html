εgo gives a model tools, sessions and a contract, then decides which of its proposals actually run. One self-contained binary serves your terminal, your scripts, your editor and any MCP client.

01

Every action earns its run.

The model proposes; εgo prepares one canonical operation and issues a permit bound to that exact call. If this host cannot prove the confinement you asked for, nothing runs: εgo refuses rather than quietly weakening the guarantee.

  • .env reads return key names, never values, unless your own exact rule reveals that file.
  • SSH, AWS, .netrc and keychain reads are denied by default.
  • Secret-named environment values are masked in output, exports and status.
  • Hooks can block or escalate. They can never grant.
Permissions and confinement

02

A token economy built into the harness.

εgo keeps the request prefix cacheable and shows you the cache. Build noise never reaches the model as noise, and large output arrives as a head, a tail and a reference the model can page.

  • Status line cache-hit rate; a live countdown with {{ cache }} in your template.
  • Opt-in idle compaction runs just before the cache expires, while reading the context still costs the cache-read price.
  • Child agents can fork from the current conversation to reuse its cached prefix, where the provider allows.
  • Opt-in learned build recipes: data, never code, and they never drop error lines.
Tools and output

03

Sessions you can audit, branch and undo.

Every session is an append-only event log. Fork at any completed turn without touching the source. Rewind files and conversation together, and when a file changed outside εgo, rewind refuses instead of overwriting your work.

  • Pre-edit bytes are kept as Git checkpoints that never touch HEAD or the index.
  • ego resume ID --queue waits until a busy session is idle, then delivers.
  • ego export writes Markdown, JSON or a transcript, sanitized on request.
Sessions and history

04

A contract for scripts and CI.

Headless runs are untrusted and bare by default: no prompts, no project content until you trust it. Answers validate against your JSON Schema, every run is bounded, and the exit code says why it stopped.

  • --budget '2.5$' or '400k', --max-turns, --timeout.
  • Retries and fallback models only after a delivery-safe failure.
  • --goal keeps working until your own --goal-check-command answers achieved.
  • Agent files are executables with declared {{variables}}, never shell evaluation.
Automation and agent files

05

One binary for every host and any model.

The terminal, a CI job, an editor and another agent drive the same session machinery under the same permits. Bring a key, a subscription or a local model, and keep several accounts per vendor apart with named connections.

  • ego acp serves editors and hosts over the Agent Client Protocol.
  • ego mcp-server gives any MCP client governed, budgeted runs, not a shell.
  • As an MCP client: stdio and HTTP servers, browser OAuth, and opt-in MCP Tasks that wake an idle session.
  • Missing model capabilities fail explicitly instead of degrading in silence.

And the details that keep it honest.

  • Authority delta on resume

    A resumed session that would get wider authority asks first; headless it stops with exit 3 unless you pass --accept-authority-delta.

  • Rules you can explain

    ego rules explain shows how one prepared call would be decided, without running it. Every rule has an ID you can revoke.

  • Workspace trust

    A cloned repository's config, instructions and skills load only after you trust it.

  • Managed worktrees

    --worktree BRANCH works on an approved new branch; cleanup refuses unmerged or dirty work.

  • Protocol filter

    A program you review can mask or refuse outgoing provider requests, MCP calls and hook payloads.

  • Honest accounting

    Cost is an exact decimal. An unpriced request makes the total unknown, never zero.
