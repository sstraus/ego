Install εgo

One executable. No installer writes configuration; ~/.ego appears only when εgo first needs to store something.

Homebrew

macOS and Linux. Shell completions for Bash, Zsh and Fish are installed too.

brew install sstraus/tap/ego

Direct download

Each release provides a plain executable and its SHA-256 file. Verify before you install.

PlatformAsset
macOS, Apple siliconego-macos-arm64
macOS, Intelego-macos-x64
Linux x86_64 (glibc 2.35+)ego-linux-x64
Linux ARM64 (glibc 2.35+)ego-linux-arm64
Windows x86_64ego-windows-x64.exe
 
asset=ego-macos-arm64
base=https://github.com/sstraus/ego/releases/latest/download
curl -fLO "$base/$asset"
curl -fLO "$base/$asset.sha256"
shasum -a 256 -c "$asset.sha256"
install -m 755 "$asset" "$HOME/.local/bin/ego"

On Linux use sha256sum -c. On Windows compare with Get-FileHash -Algorithm SHA256 and rename the file to ego.exe in a folder on PATH. Windows runs without workspace, read-only and offline confinement for now; εgo refuses those options there rather than ignoring them.

From source

Rust 1.95 or newer.

git clone https://github.com/sstraus/ego
cd ego
cargo install --locked --path crates/ego-cli

First run

  1. Make one provider usable: export its API key, run ego auth login PROVIDER for a subscription, or start a local Ollama.
  2. Run ego setup to see which providers are ready and save a default model.
  3. Run ego inside a repository and ask it something about the code.
ollama pull qwen3
ego -m ollama/qwen3 --sandbox workspace

Next: permissions and confinement, providers and login, or the full user guide.
